# 📈Gráfico de Pizza com Dados de Excel

O projeto apresenta um gráfico de pizza criado a partir de dados obtidos de uma planilha do Excel, permitindo visualizar e comparar as informações de forma gráfica.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Excel

## Desenvolvimento

Projeto desenvolvido individualmente, com orientação e apoio do professor.
